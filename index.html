💡 スプレッドシート連携の仕組み:
定型文を追加・削除すると、Googleスプレッドシート内の「定型文」シートへ自動更新されます。他の端末でアプリを開いた際も自動的に同じ定型文が読み込まれます。

トラブルシューティング・接続設定

ホーム画面に追加するとアプリ感覚で即起動！

ブラウザのアドレスバーが消えて全画面表示になり、毎回のURL入力なしで1タップ起動できます。

iPhone (Safari) の場合

共有ボタン ➔ 「ホーム画面に追加 ➕」 ➔ 右上「追加」

Android (Chrome) の場合

メニュー ➔ 「ホーム画面に追加」または「アプリをインストール」

【マイクで「not allowed」エラーが出る場合】

  1. Gmail等のアプリ内表示から開いている場合は右上「⋮」から「Chromeで開く」を選択。
  2. アドレスバー横の「🔒鍵マーク」をタップ ➔ 「サイトの設定」からマイクを「許可」に変更。
  3. スマホ本体の「設定」➔「アプリ」➔「Chrome」➔「権限」でマイクを「許可」に。

【GAS設定手順】

  1. Googleスプレッドシートを作成し「拡張機能」➔「Apps Script」を開く。
  2. `Code.gs` に「最新GASコード」タブの内容を貼り付けて保存（Ctrl+S）。
  3. 右上「デプロイ」➔「新バージョン」で再デプロイ（アクセス権は「全員」）。

以下の最新コードを `Code.gs` に上書き保存して「新バージョン」で再デプロイしてください：

function doGet(e) {
  if (e.parameter && e.parameter.action === 'getPresets') {
    return getPresetsOutput();
  }
  if (e.parameter && e.parameter.action === 'getLogs') {
    return getLogsOutput();
  }
  return ContentService.createTextOutput("目安箱 API サーバー正常動作中")
    .setMimeType(ContentService.MimeType.TEXT);
}

function doPost(e) {
  try {
    var data = JSON.parse(e.postData.contents);
    var ss = SpreadsheetApp.getActiveSpreadsheet();
    
    // 定型文の更新処理
    if (data.action === 'updatePresets') {
      var presetSheet = ss.getSheetByName('定型文') || ss.insertSheet('定型文');
      presetSheet.clear();
      presetSheet.appendRow(['定型文']);
      if (Array.isArray(data.presets)) {
        data.presets.forEach(function(p) { presetSheet.appendRow([p]); });
      }
      return ContentService.createTextOutput(JSON.stringify({ status: 'success', message: '定型文更新完了' }))
        .setMimeType(ContentService.MimeType.JSON);
    }
    
    // 通常の意見投稿処理
    var sheet = ss.getSheetByName('意見一覧') || ss.getSheets()[0];
    if (sheet.getLastRow() === 0) {
      sheet.appendRow(['日時', '投稿者', '種類', '内容']);
    }
    var now = Utilities.formatDate(new Date(), Session.getScriptTimeZone(), 'yyyy/MM/dd HH:mm:ss');
    sheet.appendRow([now, data.person || '未入力', data.category || '未分類', data.memo || '']);
    
    return ContentService.createTextOutput(JSON.stringify({ status: 'success', message: '送信完了' }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch(err) {
    return ContentService.createTextOutput(JSON.stringify({ status: 'error', message: err.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

function getPresetsOutput() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName('定型文');
  var presets = [];
  if (sheet && sheet.getLastRow() > 1) {
    var values = sheet.getRange(2, 1, sheet.getLastRow() - 1, 1).getValues();
    presets = values.map(function(r) { return r[0]; }).filter(function(v) { return v; });
  }
  return ContentService.createTextOutput(JSON.stringify({ status: 'success', presets: presets }))
    .setMimeType(ContentService.MimeType.JSON);
}

function getLogsOutput() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName('意見一覧') || ss.getSheets()[0];
  var logs = [];
  if (sheet && sheet.getLastRow() > 1) {
    var values = sheet.getRange(2, 1, sheet.getLastRow() - 1, 4).getValues();
    logs = values.map(function(r, idx) {
      var dateVal = r[0];
      var dateStr = '';
      if (dateVal instanceof Date) {
        dateStr = Utilities.formatDate(dateVal, Session.getScriptTimeZone(), 'MM/dd HH:mm');
      } else {
        dateStr = String(dateVal || '');
      }
      return {
        id: 'gas_' + idx,
        date: dateStr,
        person: String(r[1] || '未入力'),
        category: String(r[2] || '未分類'),
        content: String(r[3] || '')
      };
    }).reverse();
  }
  return ContentService.createTextOutput(JSON.stringify({ status: 'success', logs: logs }))
    .setMimeType(ContentService.MimeType.JSON);
}
